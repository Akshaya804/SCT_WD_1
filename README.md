# SCT_WD_1
A responsive web page with interactive nav bar built using HTML and CSS as part of SkillCraft Technology Web Development Internship – Task 1.
This project is a fully responsive multi-page landing website developed during my internship at SkillCraft Technology. It represents a Campus Café concept and focuses on creating a modern, user-friendly interface with interactive navigation and clean design.

🚀 Features
Responsive multi-page layout (Home, Menu, About, Contact)
Fixed navigation bar with active link highlighting
Scroll-based navbar color transition
Dynamic search functionality with item filtering
Menu section with styled product cards and pricing
Modern About and Contact page layouts
Professional footer with social media icons
Clean and consistent UI design

🛠 Technologies Used

HTML5
CSS3 (Flexbox & Grid, Responsive Design)
JavaScript (DOM manipulation & interactivity)

🎯 Purpose

This project demonstrates my ability to design responsive layouts, build interactive UI components, and create visually appealing front-end web interfaces.
